隐私政策

我们尽量少收集数据，并清楚说明浏览器里发生了什么。

我们处理哪些数据

测试题答案和五维分数在你的浏览器中计算。网站不要求账户注册，不读取银行账单、订单记录、支付信息、通讯录、精确位置、相册或设备文件。刷新页面或关闭标签页后，普通测试状态不会作为账户记录保存在我们的服务器中。

语言偏好可能保存在浏览器 localStorage 中，用于下次继续显示中文或英文。你可以通过清除站点数据删除该偏好。

好友邀请链接

当你生成好友邀请链接时，链接的 URL Hash 中会包含生成双人结果所需的人格类型、维度分数及测试结果字段。普通网页请求不会把 Hash 自动发送给服务器，但收到链接的人、浏览器扩展或能够读取剪贴板的软件可能看到这些内容。

请只把好友链接分享给你信任的人，不要在答案或反馈中加入姓名、账号、账单或其他敏感信息。

访问统计与 Cookie

网站使用 Umami Cloud 了解页面访问和核心功能使用情况，例如开始测试、完成测试、生成分享图和复制好友链接。事件参数限于人格类型及是否存在好友结果等非敏感信息，不主动发送完整答案数组或完整邀请 Hash。

托管服务、内容分发网络和浏览器可能为安全、缓存或基础运行记录 IP 地址、User-Agent 和请求时间。相关数据由各服务提供商按照其政策处理。

Google AdSense 与广告

网站未来可能使用 Google AdSense 展示广告。Google 及其合作伙伴可能使用 Cookie、本地存储或类似技术，根据访问情况投放、衡量和限制广告。对于法律要求的地区，我们会使用合适的同意管理机制，让用户选择个性化或非个性化广告。

你可以访问 Google 的广告设置管理个性化广告，也可以通过浏览器设置限制或删除 Cookie。广告不应伪装成测试答案或放置在容易导致误触的位置。

你的选择、儿童与政策更新

你可以不使用好友互测、不生成分享图、使用广告拦截或浏览器隐私设置，并随时清除本地站点数据。本服务不以儿童为目标，也不会主动收集年龄或儿童个人信息。

政策发生重要变化时，本页顶部的更新日期会调整。隐私问题可通过项目 GitHub Issues 提交，但请勿公开敏感个人资料。
